# 项目罗盘 · Project Compass

这里提供 Windows 桌面版安装包、中文操作说明书和版本记录。

## 下载 V3.2.2 beta

打开 [V3.2.2 beta 预发行页面](../../releases/tag/v3.2.2-beta)，在 **Assets** 下载 `Project-Compass-3.2.2-beta-Windows-Update.zip` 和中文操作说明书。发布说明提供 SHA-256。

## 安装与升级

完整解压 ZIP，运行 `ProjectCompass-Update.exe`。打开项目罗盘后，在窗口标题或页脚核对版本。桌面版需要 Windows x64、.NET Framework 4.7.2 或更新版本，以及 Microsoft Edge WebView2 Runtime。

升级时，更新器会为同一 Windows 用户的现有工作区创建备份。
